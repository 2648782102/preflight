# Code of Conduct

Preflight follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, welcome newcomers, and keep feedback about the code. Harassment, insults and personal attacks are not tolerated in issues, pull requests or any other project space.

To report a problem, open an issue or contact the maintainer through their GitHub profile. Reports are handled privately and promptly.
